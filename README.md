# Run Grails Geb Functional Tests with multiple Browsers

This repository contains the worked sample app for the [Run Grails Geb Functional Tests with multiple Browsers](https://grails.apache.org/guides/grails-geb-multiple-browsers/4/guide/index.html) guide on the Apache Grails site.

## Run the example

`./gradlew bootRun`

## Maintained at apache/grails-static-website

The guide narrative is maintained at https://github.com/apache/grails-static-website. Changes to the guide content go there; this repo holds the worked sample app only.
